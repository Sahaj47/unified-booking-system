# Unified Resource Booking System - Report Generator

This repository contains the Python script used to programmatically generate the official project report and documentation for the **Unified Resource Booking System** (Database Systems Course Project).

## 📄 The Output
You can view the final generated PDF here: [URBS_Project_Report.pdf](./URBS_Project_Report.pdf)

## 🛠️ Tech Stack
* **Language:** Python 3
* **Library:** ReportLab (for programmatic PDF generation)
* **Features:** Dynamic table generation, custom HEX color palettes, exact millimeter-level margin handling, and automated text wrapping.
